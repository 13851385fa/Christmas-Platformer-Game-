# Christmas Platformer Game 🎄

A small 2D platformer game developed as a personal project to practice
fundamental programming and problem-solving concepts.

## Technologies
- HTML5
- CSS3
- JavaScript (game logic and interactions)

## Features
- Player movement and jumping mechanics
- Platform collision detection
- Score tracking system
- Basic game loop and state handling

## What I Learned
- Implementing a simple game loop
- Handling keyboard input
- Designing collision logic
- Structuring a small front-end project

## How to Run
Open `index.html` in a web browser.
